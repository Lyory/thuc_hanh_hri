# MediaPipe Gesture Recognizer

Official pretrained bundle, float16, version 1:

https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/1/gesture_recognizer.task

SHA256: `97952348cf6a6a4915c2ea1496b4b37ebabc50cbbf80571435643c455f2b0482`

The bundle contains `hand_landmarker.task` and `hand_gesture_recognizer.task`.
This project uses `Closed_Fist`, `Open_Palm`, `Pointing_Up`, `Thumb_Up`, `Victory`.
`Wave` is derived from open-palm wrist motion across frames, not a pretrained label.

Model documentation and terms:
https://ai.google.dev/edge/mediapipe/solutions/vision/gesture_recognizer
